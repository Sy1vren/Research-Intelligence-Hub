# 中国计算机软件著作权保护与登记规则

## 1. 资源简介

本资源卡汇集软件著作权申请准备最相关的两项基础规则：

- 《计算机软件保护条例》：国务院公布，文本根据2011年和2013年决定修订，规定软件作品、软件著作权及权属等基本事项。
- 《计算机软件著作权登记办法》：国家版权局令第1号，2002年2月20日公布施行，规定登记申请、鉴别材料、证明文件、审查和登记事项。

国家版权局当前部门规章目录仍列有《计算机软件著作权登记办法》。国家版权局公布的登记机构名录列明中国版权保护中心及其登记网站。

## 2. 解决的问题

- 了解软件著作权保护对象及登记制度的基本法律框架。
- 识别独立开发、合作开发、委托开发和任务开发等情况下的权属风险。
- 整理软件登记申请表、程序和文档鉴别材料及权属证明。
- 避免把登记证书理解为对软件算法思想、功能或技术方案的专利授权。

## 3. 核心价值

- 软件通常包括计算机程序及其有关文档；软件著作权保护不延及开发软件所用的思想、处理过程、操作方法或数学概念本身。
- 登记办法要求申请人提交软件著作权登记申请表、软件鉴别材料及相关证明文件。
- 合作开发软件应结合书面合同明确权利归属；委托开发、任务开发等情形也应核对合同或项目任务书。
- 登记证明文件是登记事项的初步证明，不应被理解为对所有权属争议或侵权问题的终局裁判。
- 公开的法律文本还规定了程序与文档鉴别材料的基本提交规则；具体排版和电子提交要求仍须核对登记系统当前提示。

## 4. 使用方法

1. 先确认软件是否已经实际开发完成，软件名称、版本、功能和开发记录是否真实。
2. 梳理实际开发者、著作权人、共同开发成员、委托方、学校或项目承担单位之间的关系。
3. 查阅任务书、合作开发协议、委托开发协议、职务成果规定及其他权属文件。
4. 整理源程序、用户手册/设计说明书等文档，并确保材料对应同一软件名称和版本。
5. 核对第三方代码、开源组件、素材和数据的来源及许可证，保存依赖清单和许可证文本。
6. 通过中国版权保护中心当前登记网站查看最新申请流程、表格、鉴别材料格式和补正要求。
7. 保存提交版本、申请编号、受理通知、补正记录和最终登记结果。

## 5. 适用边界与局限

- 登记是软件著作权登记程序，不等于发明专利申请，也不保护抽象算法思想、功能目标或数学方法本身。
- 不能仅凭参与项目或在团队名单中出现就认定某人是著作权人；应依据实际创作、合同、任务书和法律规则判断。
- 登记办法中的页数、行数和例外交存条款来自公开法规文本。正式提交时，必须同时核对登记系统当前页面、最新办事指南及个案通知，不能机械照搬旧经验文章。
- 2026-11-24自动化访问中国版权保护中心主页时返回403，故本次未实测登录、实名认证或在线提交功能；官方登记机构名录已核对其网站域名。
- 对学校职务成果、合作开发、委托开发或开源许可证兼容问题，应由学校科研/知识产权管理部门或专业人员审查。
