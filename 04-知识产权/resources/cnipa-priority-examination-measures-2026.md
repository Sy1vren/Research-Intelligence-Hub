# 专利优先审查管理办法（2026）

## 1. 资源简介

国家知识产权局令第85号公布《专利优先审查管理办法》，2026年7月28日签发、7月30日发布，自2026年9月1日起施行；2017年公布的旧办法同时废止。

该办法规定特定专利申请、复审和无效宣告案件申请优先审查的适用条件、请求材料、推荐审核程序和办理期限。

## 2. 解决的问题

- 判断某项专利申请是否可能符合优先审查条件。
- 了解优先审查需要准备的证明材料和推荐意见。
- 避免将优先审查误认为所有申请人都能自行申请的普通加急服务。
- 为项目成果转化、关键技术攻关或已准备实施的技术成果安排申请计划。

## 3. 核心价值

办法覆盖符合条件的发明、实用新型、外观设计专利申请，以及相关复审和无效宣告案件。申请情形包括涉及新兴产业、未来产业或关键核心技术攻关，地方重点鼓励产业，已经实施或做好实施准备等情形。

一般情况下，申请人需提交优先审查请求书及与适用情形有关的材料，并按规定取得国务院有关主管部门或省级知识产权局的推荐意见；具体例外以办法条文为准。国家知识产权局对优先审查请求不另收额外费用，但专利法及实施细则规定的其他费用仍应按规定缴纳。

办法规定了经同意优先审查后的目标处理期限，也规定申请人答复期限及可能终止优先审查的情形。目标期限不是对每个案件的授权承诺。

## 4. 使用方法

1. 先确认申请类型、当前审查阶段和案件状态。
2. 对照办法第4至第8条检查是否属于适用案件及具体情形。
3. 收集能够证明创新价值、产业化准备、重点产业关联或其他法定条件的材料。
4. 确认全体申请人/权利人是否需要共同同意，并核对推荐部门要求。
5. 按国家知识产权局当前电子业务系统和最新表格提交。
6. 获准后，将官方通知中的答复期限纳入项目日历，安排专人跟踪。

## 5. 适用边界与局限

- 不是所有高校科研项目、学生竞赛成果或软件项目都符合优先审查条件。
- 是否推荐、是否同意优先审查由相应主管机关依法审核决定。
- 目标处理期限不等于必然授权，也不构成授权质量保证。
- 2026-09-01起适用新办法；此前已经提交的请求按官方过渡通知处理。
- 地方推荐细则、具体表格和系统入口可能更新，办理前须查看申请人所在地省级知识产权局和国家知识产权局当前通知。
