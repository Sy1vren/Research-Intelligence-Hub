# 国家知识产权局专利检索及分析系统

## 1. 资源简介

国家知识产权局建设的智能化专利检索及分析系统，面向社会公众提供专利检索、专利分析、专利文献浏览和数据下载等服务。国家知识产权局于2023年发布系统介绍，说明该系统对原公众检索系统进行了升级，并扩充专利数据资源和分析功能。

## 2. 解决的问题

- 在撰写专利技术交底材料前检索相关现有技术。
- 了解某一技术领域已有专利的申请人、公开时间和技术布局。
- 查找与团队方案相近的专利文献，减少重复研发和盲目宣称创新。
- 为专利代理师沟通、技术方案比对和研究背景整理提供检索线索。

## 3. 核心价值

平台是国家知识产权局的官方检索入口，适合开展初步专利检索和专利信息分析。可将检索结果作为现有技术调查的起点，并结合专利全文、法律状态及其他权威数据库进一步核实。

## 4. 使用方法

建议采用可复现的检索记录：

1. 将技术方案拆分为核心对象、关键结构/步骤、技术功能和应用场景。
2. 为每个概念建立中文同义词、行业术语和可能的英文关键词。
3. 分别检索标题、摘要、权利要求、申请人和分类号等字段。
4. 对高相关结果记录公开号/申请号、标题、申请人、申请日、公开日、摘要、权利要求和原始链接。
5. 进一步查看专利全文、同族、引用关系及法律状态；关键状态应回到官方公告或业务系统确认。
6. 保存检索日期、检索式、筛选条件和排除理由，形成可复核的检索日志。
7. 将最接近的现有技术与本方案逐项对比，区分已知特征、区别特征和待验证的技术效果。

## 5. 适用边界与局限

- 检索结果受数据库覆盖范围、字段、语言、索引延迟和检索式影响，不能证明“全球不存在相同技术”。
- 检索平台中的公开信息不能替代正式法律状态核验、专利稳定性分析或专业专利检索意见。
- 不能只凭标题或摘要判断技术方案是否相同，应阅读说明书和权利要求。
- 下载、批量处理或再发布数据时，应核对平台条款及相关数据权利限制。
- 本次核对的是国家知识产权局官方系统介绍和入口；未执行登录、批量检索或下载测试。
