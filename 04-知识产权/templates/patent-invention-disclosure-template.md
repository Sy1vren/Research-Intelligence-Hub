# 专利技术交底信息采集模板（RIH 原创工作模板）

> **用途：** 在与专利代理师沟通或撰写正式申请文件前，结构化收集发明/实用新型的技术事实。  
> **性质：** 团队内部信息采集模板，不是国家知识产权局官方表格，不构成专利性判断或法律意见。  
> **保密提醒：** 填写版可能包含未公开技术秘密。不要把填写后的文件、图纸、源代码或实验原始数据直接提交到公开 GitHub 仓库；应存放在团队批准的私有空间。

## 使用说明与限制

1. 先由实际研发人员填写技术事实，项目负责人核对时间线、证据和版本。
2. 专利检索应记录检索式、数据库、日期和结果，不能仅凭关键词搜索结果宣称“全球首创”。
3. 本模板用于沟通和信息整理，不代替专利请求书、说明书、权利要求书等正式申请文件。
4. 申请类型、发明人、申请人、权利归属和公开影响应由专利代理师或学校知识产权管理部门进一步复核。
5. 本模板为 RIH 自主编写，尚未经过真实专利申请试填，当前不得标记为 ADAPTED。
