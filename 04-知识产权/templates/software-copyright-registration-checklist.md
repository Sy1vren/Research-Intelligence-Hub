# 软件著作权登记材料准备清单（RIH 原创工作模板）

> **用途：** 为真实开发完成的软件整理登记申请信息、程序/文档鉴别材料和权属证明。  
> **性质：** 内部准备清单，不是中国版权保护中心官方申请表，也不保证登记受理或通过。  
> **重要提醒：** 不要将身份证明、签名、合同、未公开源代码或敏感项目资料上传至公开仓库。

## 一、软件真实状态确认

- [ ] 软件已经实际开发完成，能够说明其实际功能。
- [ ] 软件名称、简称（如有）和版本号已确定。
- [ ] 开发完成日期有真实记录。
- [ ] 首次发表情况已核实；未发表时如实填写。
- [ ] 已保存对应版本的源代码、构建文件、用户文档和开发记录。
- [ ] 软件说明与当前代码实现一致，不把计划功能写成已实现功能。
- [ ] 如软件尚未完成，先明确是否具备申请条件，不虚构完成日期或功能。

## 二、开发者、著作权人和权属核查

- [ ] 实际开发者及其贡献已记录。
- [ ] 拟登记的著作权人已明确。
- [ ] 共同开发的，已查阅书面合作开发协议并确认权利约定。
- [ ] 委托开发的，已查阅委托合同中的软件著作权归属条款。
- [ ] 由学校、单位或项目任务书组织开发的，已核对任务书、职务成果制度及相关协议。
- [ ] 涉及受让、继承或承受权利的，已准备相应证明。
- [ ] 申请表、源程序、文档和证明材料中的软件名称、版本和权利人信息保持一致。
- [ ] 未将指导教师、项目负责人、出资人或团队成员身份直接等同于著作权人。

## 三、第三方代码和开源许可证核查

- [ ] 已生成依赖清单，记录库/组件名称、版本、来源和许可证。
- [ ] 已检查复制、修改或嵌入的第三方代码。
- [ ] 已保存 MIT、Apache-2.0、GPL、BSD 等许可证原文及对应版本。
- [ ] 已核对许可证的署名、版权声明、源码提供、再分发或衍生作品义务。
- [ ] 不清楚来源或许可证的代码已隔离，不直接并入申请版本。
- [ ] 已确认团队对提交的软件表达具有相应权利，且没有隐瞒第三方权利。
- [ ] 对有冲突或不确定的许可证，已咨询专业人员。

## 四、申请材料清单

依据《计算机软件著作权登记办法》第九至第十三条，通常应准备：

- [ ] 按当前登记系统要求填写的软件著作权登记申请表。
- [ ] 软件鉴别材料：程序鉴别材料和文档鉴别材料。
- [ ] 申请主体身份证明或主体资格材料。
- [ ] 合作开发合同、项目任务书、委托开发协议或其他权属证明（适用时）。
- [ ] 许可、受让、继承或承受权利的证明（适用时）。
- [ ] 登记系统要求的其他补充材料。

## 五、程序与文档材料一致性

- [ ] 源程序来自拟申请登记的软件版本，而非其他项目或旧版本。
- [ ] 文档能够真实描述软件的组成、设计、功能、开发情况、测试结果或使用方法。
- [ ] 软件名称和版本号在申请表、程序材料、文档材料中一致。
- [ ] 已检查代码中是否包含密钥、密码、访问令牌、个人信息或不应公开的项目数据。
- [ ] 已确认提交材料中第三方代码和保密内容的处理方式符合权利及登记要求。
- [ ] 已保留提交材料的只读归档副本及校验值/版本记录。

### 关于页数和格式的特别提醒

国家版权局令第1号第十条载有程序和文档鉴别材料的基本页数及行数规则，并在第十二条规定了例外交存方式。但正式提交时，必须再次核对中国版权保护中心登记系统当前页面、最新办事指南及个案通知。不要仅凭旧教程或代理机构宣传页决定页数、行数、页眉、格式和文件大小。

## 六、线上办理前检查

- [ ] 已从国家版权局公布的办理机构名录确认登记机构及官方网站。
- [ ] 已在中国版权保护中心当前登记系统核对入口。
- [ ] 著作权人账号及实名认证按系统要求完成。
- [ ] 申请表字段已由权利人/经办人核对。
- [ ] 所有附件均符合当前系统文件格式和大小要求。
- [ ] 申请前已确认权属无争议。
- [ ] 已由项目负责人或学校知识产权管理部门复核。
- [ ] 已保存提交时间、申请编号和提交文件版本。

## 八、归档和安全

- [ ] 申请表、程序材料、文档、权属证明和通知分开归档。
- [ ] 个人身份证明、联系方式、签名和合同放入受控私有空间。
- [ ] 源代码仅按权利人授权和登记要求提供，不放入公开 GitHub。
- [ ] 公开知识库只记录脱敏后的软件名称、版本、申请流程经验和公开登记信息。
- [ ] 对外公开软件或代码前，已完成专利申请优先级和商业秘密审查。

## 使用边界

1. 登记材料和系统要求可能变化，提交当天以官方登记系统和正式通知为准。
2. 登记证书是登记事项的初步证明，不代表对全部权属争议或侵权争议作出终局认定。
3. 软件著作权不等同于专利权；算法思想、功能目标或数学概念本身不因登记而获得软件著作权保护。
4. 本清单为 RIH 自主编写，尚未用团队真实软著申请完整试填，当前不得标记为 ADAPTED。
