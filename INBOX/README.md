# 候选资源收件箱

INBOX 用于暂存尚未完成评估的资源线索。这里不是正式知识库，不能将收件箱内容直接视为可靠知识或推荐依据。

## 收录规则

每条候选资源至少记录：
- 资源标题或暂定名称；
- 原始 URL 或发现入口；
- 发现日期；
- 可能所属模块；
- 发现原因或待解决问题；
- 当前状态，默认 DISCOVERED；
- 下一步核验事项。

## 处理流程

1. 检查链接是否指向原始发布者或官方维护页面。
2. 核对作者/机构、版本、发布日期、许可和访问条件。
3. 检查内容质量、时效性、相关性及重复情况。
4. 通过核验后，按 SYSTEM/RESOURCE_RECORD_SCHEMA.md 建立正式资源卡。
5. 更新对应模块索引和 RESOURCE_CATALOG.md。
6. 对失效、低质量、重复或不合规资源，记录原因并移出候选队列；必要时保留简短淘汰记录。

## 禁止事项

- 不得把未经核验的链接标记为 VERIFIED。
- 不得仅凭搜索摘要判断资源内容。
- 不得上传受版权保护的整本资料、账号凭证、密钥或私人数据。
- 不得将候选资源数量当作知识库建设成果。
