# NASA KSC Technical Documentation Style Guide（KSC-DF-107）

## 1. 资源简介

NASA 肯尼迪航天中心（KSC）工程部门发布的技术文档写作与格式指南。官方记录标注版本为 Revision F、Change 0，文件日期为 2017-07-08；NASA Technical Standards System 当前将该版本标记为 ACTIVE，并标明可通过互联网公开访问。

指南覆盖技术文档的语言表达、术语一致性、缩写、数字与单位、公式、图表标题、引用、文档结构、封面、签署页、修订记录、摘要、目录及正式文件/工程文件的格式差异。

## 2. 解决的问题

适合解决工程说明书、技术报告、设计文件和项目交付文档中常见的以下问题：

- 章节层级和文档要素不统一；
- 术语、缩写、数字、单位和图表标注前后不一致；
- 技术要求、建议、预测和事实陈述混用；
- 引用文件和具体条款无法追溯；
- 版本修订记录、签署和文件控制不完整；
- 文字冗长、表达含糊或难以供技术人员复核。

## 3. 核心价值

- 区分正式文件与特定项目的工程文件，提示两类文件在权威性、审查和格式上的差异。
- 提供清晰、简洁、准确、一致的技术表达原则。
- 对 shall、should、will、must 等要求性用语作出区分；跨语言应用时应先建立项目自己的术语表，不能机械翻译。
- 系统覆盖图表、公式、数字、缩写、引用、修订记录和文档组成部分。
- 官方指南提及 KSC 自用的 Word 模板入口，可作为理解文档控制要素的线索；本仓库不复制或再发布这些模板。

## 4. 使用方法

1. 先从 NASA 官方记录确认文件编号、版本、日期和 ACTIVE 状态，不使用搜索引擎转载件代替原始来源。
2. 根据当前文件用途，优先查阅指南中对应章节：写作与格式、图表、引用、工程文件总体格式、修订记录等。
3. 将其作为编辑和质量控制参考，而不是直接把 KSC 的版式要求当作中国高校、行业或项目的强制要求。
4. 对本项目建立统一术语表、缩写表、单位规则、图表编号规则和修订记录。
5. 结合本模块的《工程技术报告模板》和《技术文档审查清单》执行编制与复核。

## 5. 适用边界与局限

- 官方适用范围是 KSC 各部门及合同明确要求适用的承包商；其格式规定针对 KSC 的正式文件和工程文件。
- 对中国高校科研项目、道路桥梁工程、竞赛材料和国内工程交付文件，只能选择性借鉴写作、结构和可追溯性原则。
- 它不是中国国家标准、行业标准，也不替代项目任务书、合同、学校模板或现行工程规范。
- NASA 的术语用法和英文排版规则不能未经转换直接套用于中文技术文档。
- 虽然文件标注公开发布和无限制分发，但本仓库不复制全文、图表或其模板；实际再利用前仍应遵循 NASA 网站使用条款和相关权利声明。
