# FHWA 桥梁检查资源入口

## 资源简介
美国联邦公路管理局桥梁检查资源页面，汇集桥梁检查参考手册、潜水检查手册、质量控制/质量保证框架及相关技术资料。

## 解决的问题
为桥梁结构检查、病害识别、检查记录、质量控制和水下基础检查提供系统性参考资料入口。

## 核心价值
- 页面列出 Bridge Inspector's Reference Manual（BIRM，2022 NBIS 版本，2023年3月发布）。
- 提供 Underwater Bridge Inspection Reference Manual（2024年9月）等资料。
- 可用于理解桥梁检查工作的组织方式、检查项目和记录体系。

## 使用方法
1. 先阅读资源页面，确认手册名称、版本和发布日期。
2. 根据学习主题选择桥梁检查基础、结构构件、检查记录或水下检查资料。
3. 阅读时建立“构件—典型病害—检查方法—记录要求—评定依据”对照表。
4. 将美国 NBIS/FHWA 体系与中国现行规范、行业标准及项目要求区分，不直接替代国内规范。

## 适用边界与局限
该资源基于美国桥梁检查制度和术语体系，不能直接作为中国工程项目的法定检测或评定依据。具体 PDF 的版权和使用条件应分别核查。
