科研智能知识库 · Research Intelligence Hub

Build Knowledge. Develop Methods. Create Intelligence.

一个面向科研创新、工程实践与学术发展的长期知识体系。

Research Intelligence Hub（RIH）致力于整合全球优质科研资源，沉淀科学研究方法，构建可复用的科研工作流程，为科研项目、学术研究、工程实践和创新竞赛提供持续支持。

⸻

1. 为什么建立这个知识库？

科研能力的提升，不应该每次都从零开始。

优秀的研究方法、工程经验、技术规范、开源工具和项目案例，往往分散在不同的论文、网站、数据库和代码仓库中。

RIH希望解决三个问题：

* 知识分散：把有价值的知识和资源组织起来。
* 经验无法复用：把有效的方法沉淀为标准化流程和工具。
* 科研效率不足：让每一次研究都能够利用已有积累，而不是重复探索。

我们希望建立的不是一个简单的资料收藏夹，而是一个能够持续成长的科研能力基础设施。

5. 资源质量原则

我们不以资源数量作为知识库的主要评价标准。

每项重要资源都应尽可能经过以下检查：

1. 来源是否可靠？
2. 内容是否准确？
3. 版本是否有效？
4. 是否具有实际应用价值？
5. 是否存在版权或许可证限制？
6. 是否能够复现、运行或验证？
7. 能否形成可复用的方法或能力？

资源状态分为：

* DISCOVERED：已发现。
* REVIEWED：已初步审查。
* VERIFIED：已完成必要核验。
* ADAPTED：已结合实际任务适配。
* DEPRECATED：已过时或不再推荐。

未经核验的资料不得标记为已经验证。

6. 如何使用本知识库？

方式一：通过GitHub直接查阅

1. 阅读 INDEX.md，了解整体结构。
2. 进入对应模块目录。
3. 阅读该模块的 SKILL.md。
4. 根据目录查找相关资源。
5. 按照资源说明开展实际工作。

方式二：通过ChatGPT协同使用

在GitHub连接授权有效且相关工具可用的情况下，可以让ChatGPT按需读取仓库文件。

推荐工作流程：

1. 根据任务确定相关模块。
2. 读取总索引。
3. 读取对应模块的工作规范。
4. 检索相关资源。
5. 结合任务分析、整理和应用。
6. 将有价值的新成果沉淀回知识库。

例如：

* 准备科研竞赛：调用01、02、06、07。
* 编写科研项目申报书：调用02、06、07、09。
* 开展桥梁结构研究：调用06、07、08、09。
* 撰写学术论文：调用05、06、07、09。
* 申请科研专利：调用03、04、07。

注意： GitHub连接提供的是按需读取能力，不代表仓库内容自动成为模型的永久训练知识，也不代表模型会在后台自动学习所有文件。

7. 资源贡献与维护

知识库将持续吸收高质量资源。

欢迎整理和贡献：

* 权威科研资料。
* 优秀学术论文与研究方法。
* 项目申报书和竞赛优秀案例。
* 工程技术规范与计算实例。
* 高质量开源代码与科研工具。
* 公开数据集与数据库。
* 可复用的科研模板和工作流程。

每项资源应保留原始来源、版本、适用范围和使用限制。

遵守知识产权、开源许可证、学术规范与数据安全要求。
