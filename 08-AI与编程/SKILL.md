# 08 AI 与编程（AI & Programming）

## 一、模块定位

本模块旨在建立能够真正服务科研与工程实践的人工智能和编程能力。

核心目标：

将编程从单纯的代码编写工具，转变为解决科研问题、处理工程数据、提高研究效率、开发专业工具和实现工作流自动化的基础能力。

本模块重点建设以下方向：

1. Python编程基础
2. 科学计算与数据分析
3. 数据可视化
4. 机器学习
5. 深度学习
6. 大语言模型与提示工程
7. API与工具调用
8. AI Agent与自动化
9. Git与GitHub协作
10. 科研软件与应用开发
11. 工程计算与智能分析
12. AI辅助科研工作流

基本原则：

- 以实际问题为导向，不为学习编程而学习编程。
- 优先掌握科研中高频、可复用的技术。
- 所有代码应尽量可运行、可解释、可复现。
- 不把AI生成的代码默认视为正确。
- 重要计算结果必须经过独立验证。
- 关注工具的适用边界、数据安全和知识产权。

### 2.1 基础语法

系统掌握：

- 变量与数据类型
- 字符串与数值运算
- 列表、元组、字典和集合
- 条件判断
- 循环
- 函数
- 模块与包
- 文件读写
- 异常处理
- 面向对象编程
- 迭代器与生成器
- 装饰器基础

学习要求：

能够独立编写结构清晰、逻辑正确、具有基本错误处理能力的程序。

### 2.2 科研常用Python库

重点掌握：

| 库 | 主要用途 |
|---|---|
| NumPy | 数组、矩阵和数值计算 |
| Pandas | 数据整理、清洗和分析 |
| Matplotlib | 科研绘图 |
| SciPy | 科学计算与优化 |
| SymPy | 符号计算与公式推导 |
| Scikit-learn | 传统机器学习 |
| Seaborn | 统计数据可视化 |
| OpenPyXL | Excel文件处理 |

| Requests | HTTP请求 |
| BeautifulSoup | 网页解析 |
| Jupyter | 交互式科研计算 |

选择工具时应考虑任务复杂度、维护情况、许可证和数据安全。

### 2.3 编程质量

代码应具备：

- 清晰的变量命名
- 合理的函数拆分
- 必要的注释
- 输入数据检查
- 异常处理
- 结果验证
- 可复现的运行环境
- 必要的测试

对于重要项目，应提供README、依赖清单和使用说明。

## 八、AI Agent与自动化工作流

### 8.1 Agent基础

理解：

- 大语言模型
- 工具调用
- 任务规划
- 上下文管理
- 记忆机制

### 8.2 工作流自动化

重点研究：

- 定时任务
- 文件自动整理
- 数据批量处理
- 文献元数据整理
- 报告自动生成
- 邮件与日程辅助
- API工作流
- GitHub自动化
- 多工具协同

### 8.3 科研Agent应用

探索建立：

1. 文献检索与整理助手
2. 工程规范查询助手
3. 科研数据分析助手
4. 试验数据处理助手
5. 项目申报辅助助手
6. 技术报告生成助手
7. 代码检查与测试助手

- 输入

- 可调用工具
- 权限边界
- 失败处理
- 结果验证
- 人工审核环节

不得将未经审核的Agent输出直接用于重要工程决策。

### 9.2 GitHub知识库管理

## 十二、代码与项目质量控制

每个重要编程项目应具备：

1. 项目名称
2. 项目目标
3. 功能说明
4. 运行环境
5. 依赖清单
6. 输入数据说明
7. 代码结构
8. 运行方法
9. 测试记录
10. 输出结果
11. 已知限制
12. 版本记录

重要计算程序应使用独立算例或已知理论解进行验证。

涉及机器学习时，应保存数据划分方式、随机种子、模型参数和评价指标。

## 十三、AI协作与代码审查规范

AI生成代码后，必须进行以下检查：

- 是否满足实际需求？
- 是否存在语法错误？
- 是否存在逻辑错误？
- 是否存在数据类型问题？
- 是否考虑异常输入？
- 是否存在安全风险？
- 是否能够在目标环境运行？
- 结果是否符合理论预期？
- 是否存在未经授权的数据访问？
- 是否需要人工专业审核？

推荐协作流程：

明确任务
→ AI制定方案
→ 人工确认技术路线
→ AI辅助编写
→ 实际运行
→ 测试与调试
→ 独立验证
→ 整理文档
→ 归档到GitHub

## 十五、资源验证机制

每个外部资源必须明确标注状态：

- DISCOVERED：已发现，尚未完成阅读核验。
- REVIEWED：已阅读，初步判断有使用价值。
- VERIFIED：已核实来源、版本、内容和适用性。
- ADAPTED：已转化为可复用方法、代码或工作流。
- DEPRECATED：已经过时或不再推荐。

每项资源至少记录：

- 名称
- 类型
- 官方来源
- 作者或维护机构
- 链接
- 版本
- 适用场景
- 使用限制
- 验证状态
- 核验日期

优先收录官方文档、成熟开源项目和具有实际科研价值的资源。

不得仅凭GitHub星标数量、网络热度或AI推荐判断技术可靠性。

## 十六、最终建设目标

本模块最终应形成六项能力：

1. 编程能力：能够独立编写科研与工程程序。
2. 数据能力：能够处理、分析和解释科研数据。
3. 算法能力：能够理解并应用机器学习方法。
4. AI能力：能够合理调用大语言模型和智能工具。
5. 自动化能力：能够构建多步骤科研工作流。
6. 开发能力：能够将研究需求转化为可运行的软件工具。

最终目标：

建立一套以科研问题为核心、以编程为基础、以AI为增强工具、以工程实践为应用场景的技术能力体系。
